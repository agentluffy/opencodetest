### YOLO Mode

For automated workflows, use the `--yolo` flag to auto-approve all permissions (dangerous commands like `rm -rf /` are still blocked):

```bash
opencode run --yolo "your command here"
```

Or with the TUI:

```bash
opencode --yolo
```
